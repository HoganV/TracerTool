# 0.3 experimental stream implementation decisions

This implementation is a bounded experimental reach tracer, not completion of
all research work in STREAM_IMPLEMENTATION_RUNBOOK.md. The user authorized the
implementation and GitHub prerelease. Independent human labels/productivity,
clean interactive Windows/GIS acceptance and binary redistribution clearance
remain gates, not work that agents can invent.

- Keep legacy new-draft defaults. Add Auto as explicit opt-in; source release is
  class B unless independent qualification is actually established.
- Keep existing NumPy/SciPy/Rasterio dependencies; no neural model is needed for
  this first deterministic comparison, no copied GPL research implementation.
- Use source-native windows with disclosed cell budget and partial-upstream
  uncertainty; reject oversized domains, never silently downsample analysis.
- Flat-resolved D8 accumulation and directional multiscale channel evidence are
  complementary evidence, not a validated connected hydrologic network.
- Material conditioning and generalized network topology are not silently
  approximated. Missing work is documented and remains incomplete.
- Schema 2 engine provenance/migration keeps old XYZ unchanged and unknown engine
  provenance readable, but explicit execution requires a supported engine.
- Production deployment is a source prerelease. Build native portable packages
  for verification only; do not upload binaries before distribution clearance.
- Original private development history is never pushed. All outgoing commits
  descend from sanitized public main; source artifacts are explicitly audited.

## Evidence-driven revision and release policy

The initial real-data replay returned zero Auto geometries on 21 declared pilot
reaches. Seventeen refusals involved native sinks and four involved the domain
cap. The initial report is preserved with its module/data hashes. A bounded core
revision investigates numerical/flat/pit handling; these already-exposed cases
are development/validation evidence, never a newly claimed blind holdout.

Cycle 1 implemented outlet-connected flat routing, complete-depression accounting
and analysis-only treatment limited to nine cells and twice a transparent
source-Z roughness estimate. Larger/deeper retained basins still refuse; source
Z and validity are unchanged. Increasing the native domain cap to two million
cells removed four domain refusals, but **all 21 real reaches still refused at
retained basins**. No usable full pilot reach or geometric gain was demonstrated.
Measured peak child RSS was about 433 MiB and per-reach times reached 30.32 s;
the warm subsecond target was not met. The two-hypothesis cycle stopped rather
than expanding conditioning until an unsupported route appeared.

Independent review found and reproduced source mutation after solver completion,
VRT dependency/cache mismatch, and native-valid geometry vetoed by the display
mask. Guards now capture dependencies before reads, check source identity at
dispatch/install/accept, and validate Auto against the native mask. A separate
review reproduced protected-junction metadata loss after repeated edits and
malformed engine evidence; both received persistent protection/validation fixes.
Release review required clean build inputs, tracked-only copied documentation,
strict provenance schema and canonical extraction paths. These are integrity
requirements regardless of whether the experimental solver improves geometry.

The six-catchment/independent-label floor, human productivity study and complete
promotion criteria remain unmet. Publishing a clearly limited class-B source
prerelease does not close those gates or complete the entire original runbook.

Implementation agents are pinned to gpt-6-astra via openai-codex after the user's
model instruction. Earlier partial work was produced by a different model and
is being reviewed, not mislabeled as Astra-generated.
