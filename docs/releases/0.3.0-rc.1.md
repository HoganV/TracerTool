# 0.3.0-rc.1 — experimental stream research preview

This is a **source-only experimental prerelease**, not a completed usable-stream
overhaul or a promoted replacement for Legacy.

## Included

- Explicit opt-in Auto stream proposals on bounded source-native analysis grids.
- Multiscale directional channel evidence, outlet-connected flat routing,
  joint interior-guide selection and bounded analysis-only tiny-pit treatment.
- Source/dependency identity guards at read, preview and acceptance boundaries;
  native NoData checking and source-sampled XYZ preservation.
- Schema-2 engine/evidence provenance, schema-1 read migration without moving
  saved geometry, persistent protected vertices and conservative edit refusal.
- Reproducible public MN/MA pairing/evaluation scripts, failure accounting,
  hash-bound results and stricter package provenance/archive checks.

## Critical result: Auto has not demonstrated practical pilot success

Both the original and revised Auto returned **0 complete geometries on 21 real
pilot reaches**. The revision removed four domain-budget refusals, but all 21
then refused retained basins. Geometric improvement is undefined, not zero error.
The algorithm also misses the subsecond preview target. Legacy remains default.
Do not use this prerelease expecting the requested automatic stream-finding
improvement; it exposes the research tooling and guarded experiment for review.

See `evaluation/README.md` and its retained reports, `docs/STREAM_DECISIONS.md`,
and `docs/VALIDATION.md`. Data are exposed development/validation sources with
lineage/precision limitations, not independent surveyed thalwegs or blind tests.

## Compatibility and limits

Application version is 0.3.0; the Git tag adds rc.1. Projects newly saved use schema
2; keep backups before opening them in older application versions. Normal runtime
is local/offline with no model account or trained model required. Endpoints in
this experiment stay fixed; internal rough guides can move. Output detail retains
its explicit working-cell interpretation. Native analysis has a disclosed two
million cell cap and partial-upstream uncertainty. Material breaching, full
network extraction and coordinated junction editing are not delivered.

Tests, source CI, frozen checks and actual platform results are reported against
their exact candidate/merge identities in the release evidence, not inferred from
this note. No public binaries are attached: native desktop/GIS acceptance and
third-party binary distribution clearance remain open. No independent operator
productivity or hydrologic/measurement accuracy claim is made.
